# FunctionLab

FunctionLab is a modular platform for mathematical function analysis.

## Project Structure

This project is organized into three main parts:

- **Engine** – handles symbolic math processing and function analysis
- **API** – provides backend endpoints and business logic
- **UI** – frontend for user interaction and result visualization

## Architecture

User -> UI -> API -> Engine -> API -> UI

## Notes

Each part of the system is developed in its own branch/repository structure.
More detailed documentation exists in each repo.
